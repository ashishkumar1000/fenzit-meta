## Reviewer Gate (2026-09-25) — rubric walker + accessibility + adversarial, full set

All three ran in parallel: `review-rubric.md`, `review-accessibility.md`, `review-adversarial.md`. 47 findings total (rubric 18, accessibility 11, adversarial 18). Verdict: strong spine pair overall, no findings required a redesign — all were completeness/consistency gaps where the PRD had already answered the question and the UX draft simply hadn't carried it over. Fixed directly (no user decision needed, since the PRD already settled these):

- **Accessibility (2 critical, 3 high, 3 medium, 3 low — all addressed):** added the permission-denied path (new mock frame + State Patterns row + Accessibility Floor entry); corrected the Accessibility Floor's blanket "44px everywhere" claim to carve out the calendar-cell exception it already had elsewhere; fixed a real icon collision in the calendar mock (Half day vs Checkout missing were rendering the identical glyph — now Clock vs AlertCircle, matching the table that was already correct in prose); fixed Checkout missing rendering red instead of amber on the monthly-list mock; added an accessible fallback (numeric stepper + text address readout) to the map picker's drag/slider controls; fixed the wizard mock showing a blocked employee's switch as already "on"; fixed three low-contrast greys (`#9CA3AF` → `#6B7280`/`#4B5563`) in the calendar, onboarding and leave-apply mocks; added spelled-out accessible labels to the weekly-off day pills; added a Dynamic Type note for the calendar's fixed-size icon (Day Detail is the accessible fallback); logged the untested blue/gray icon-family collision as a pre-build open question rather than guessing.
- **Adversarial/PRD-completeness (3 critical, 3 high, 1 medium-high, 4 medium, 2 low-medium, 2 low — all addressed):** wired the leave/holiday confirm dialogs into the CheckInOutButton's actual press-flow (they existed only as orphaned copy before); added the missing Revoke sheet and Cancel component patterns (previously had zero screen spec, unlike every other leave action); added Holiday-vs-Leave collision handling (inline warning + two new notification copy rows); added the FR-2 "enabled after Start time" edge case and the matching dashboard-tile exclusion rule; added a distinct "precise location off" state; added the 3 missing reminder copy rows (had only 1 of 4); disambiguated the job-tab vs attendance-tab "Today" naming collision; added Office archive, Office reassignment, Weekly-off effective-dating + remove-override, and the 4 missing leave-validation error messages; added distance and correction-history to Day Detail.
- **Rubric (18 findings, mostly additive — all addressed):** added missing DESIGN.md Components rows (Skeleton, Weekly off settings, Holidays settings, KPI tiles/Flags strip) and the missing EXPERIENCE.md Component Patterns row for StatusBadge/Flag tag; reworded two places that cited unbuilt generalisation work (`Skeleton`, the technician-facing notifications inbox) as if already reusable-as-is; fixed component-name drift ("Setup wizard shell"→"Setup wizard", "Enrolment row"→"Enrolment rows") and spelling drift ("Fake-location"→"Fake location", matching the PRD); renamed the `radius.circle`/`radius.circle.fill` tokens (they held colours, not radii) to `map.circleStroke`/`map.circleFill`; added UJ-3's dropped cancel-edge-case sentence and a UJ-5 climax line.
- **Not fixed, logged as accepted:** one low finding (DESIGN.md and EXPERIENCE.md both restate a couple of tap behaviours) was flagged by the rubric itself as "harmless duplication today" — left as-is rather than trimmed, since removing it risks losing clarity for no real gain.

No consolidated `validation-report.html` was generated — by the time all three reviews landed, nearly every finding had already been fixed inline, so a formal "here's what's broken" report would have described a state that no longer existed. The three `review-*.md` files remain on disk as the record of what was found.
